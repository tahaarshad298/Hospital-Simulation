# CMSC 131 Hospital Simulation

Two parts, each a separate project that runs on its own:

- `Phase1/` - Simulation, Hospital and Patient classes (with JUnit tests)
- `Phase2/` - adds devices, observations and alerts (with JUnit tests)

## Run
Open the `Phase1` or `Phase2` folder in IntelliJ IDEA (File > Open > select the folder).
IntelliJ imports it as a Maven project and downloads JUnit automatically.

- Run the program: open `src/Main.java` and click the green Run arrow next to `main`.
- Run the tests: right-click the `test` folder > Run 'All Tests' (or `mvn test` in that folder).

Requires JDK 11 or newer.
